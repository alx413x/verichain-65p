# COMP5565 Project - Warranty dApp

Short instructions to get started with compiling and local deployment.

Requirements
- Node.js (16+ recommended)

Install

```bash
cd /path/to/project
npm install
```

Compile

```bash
npm run compile
```

Local deploy (after starting a local Hardhat node)

```bash
# in one terminal
npx hardhat node

# in another
npm run deploy:local
```

Worklog is in `WORKLOG.md` and will be updated for each change.
